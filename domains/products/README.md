# Products Domain

This microservice manages product information within the system. It provides a full set of CRUD operations for product management:

## Endpoints
- **Create Product:** Add a new product to the catalog.
- **List Products:** Retrieve a list of all products.
- **Get Product by ID:** Fetch details of a specific product by its unique ID.
- **Update Product:** Modify the information of an existing product.
- **Delete Product:** Remove a product from the catalog.

All endpoints interact with the database to ensure accurate and up-to-date product data. This service is modular and designed for scalability within the microservices architecture.
