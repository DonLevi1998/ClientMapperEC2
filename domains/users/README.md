# Users Domain

This microservice manages user accounts and related information. It provides a complete set of CRUD operations for user management:

## Endpoints
- **Create User:** Add a new user to the system.
- **List Users:** Retrieve a list of all users.
- **Get User by ID:** Fetch details of a specific user by their unique ID.
- **Update User:** Modify the information of an existing user.
- **Delete User:** Remove a user from the system.

All endpoints interact with the database to ensure persistent and reliable user data management. This service is designed to be modular and scalable as part of the overall microservices architecture.
