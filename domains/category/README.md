# Category Domain

This microservice manages product categories within the system. It provides a complete set of CRUD operations for category management:

## Endpoints
- **Create Category:** Add a new category to organize products.
- **List Categories:** Retrieve a list of all categories.
- **Get Category by ID:** Fetch details of a specific category by its unique ID.
- **Update Category:** Modify the information of an existing category.
- **Delete Category:** Remove a category from the system.

All endpoints interact with the database to ensure efficient and reliable category management. This service is modular and scalable as part of the microservices architecture.
